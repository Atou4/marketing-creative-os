# Nursery Pro — Content Pillars

| Pillar | Director angle | Educator angle | Parent angle |
|---|---|---|---|
| Time & admin | reduce operational friction | less repetitive reporting | faster information |
| Communication | parent trust / visibility | easy daily updates | stay connected |
| Daily operations | attendance, staff, records | classroom routine | confidence in the day |
| Child moments | visibility into care | capture activities | photos/reports/moments |
| Trust | access, privacy, responsibility | permissions/workflows | child-data confidence |
| Product education | see the system working | learn faster workflows | understand parent experience |

Promotional content should be a minority layer across these pillars, not a separate constant sales stream.
