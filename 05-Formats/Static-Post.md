# Static Post

A static post should communicate one idea at feed speed.

## Brief
- single message;
- hook/headline;
- visual subject;
- proof/source;
- CTA if needed;
- platform crop;
- logo treatment.

## Strong patterns
- product/UI callout;
- real-photo + concise line;
- customer language card;
- comparison;
- annotated screenshot;
- simple data visual with real data;
- announcement.

Avoid cramming a carousel into one image.
