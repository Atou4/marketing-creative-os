# Carousel

A carousel is a sequence, not a stack of independent posters.

## Narrative
1. Hook / promise
2. Context or tension
3–N. Progressive value/proof
Final. Payoff + next action

Useful architectures:
- problem → reframe → solution;
- mistake list;
- framework / steps;
- before → after;
- product walkthrough;
- objection → proof;
- story arc.

Keep each slide understandable in isolation but reward swiping. Maintain consistent grid, type, and image treatment while varying composition enough to avoid mechanical repetition.
