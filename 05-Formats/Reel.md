# Reel / Short

## Structure
- 0–2s: hook / visual interruption
- 2–7s: context or proof
- middle: demonstrate / develop
- end: payoff / CTA

## Preproduction
Concept → hook → script → shot list → references → assets/characters → generation/filming → edit → captions → QA.

For AI-generated sequences, lock product/character/location references before generating shots to reduce continuity drift.

Test pacing, text-safe areas, caption readability, audio rights, and whether the first frame works without sound.
