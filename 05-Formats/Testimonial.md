# Testimonial Creative

Only use real approved testimony.

Strong execution options:
- customer video;
- exact quote + real identity/logo if permitted;
- quote + product evidence;
- case-study micro-story;
- comment/review card with source attribution.

Do not “improve” a quote so much that it changes meaning.
