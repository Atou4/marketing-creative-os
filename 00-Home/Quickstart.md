# Quickstart

## First-time setup
1. Fill [[01-Brand-Brain/MASTER-CONTEXT]].
2. Fill the product truth files in `02-Product-Marketing/`.
3. Define 3–5 [[03-Content-Strategy/Content-Pillars]].
4. Build the initial [[04-Hooks-Angles/Hook-Bank]] and [[04-Hooks-Angles/Angle-Library]].
5. Register approved assets in [[01-Brand-Brain/Brand-Asset-Registry]].
6. Add real customer language and proof.
7. Choose formats and platforms only after the content strategy is clear.

## For a new campaign
Use `Templates/Campaign-Brief.md`, then follow:

`research → angle slate → human pick → creative brief → copy/visual → QA → approval → publish → performance review`

## For daily content
Do not ask “what should we post today?” Start from:

`persona × pillar × awareness × angle × format × platform`

Then check recent output to avoid repetition.
