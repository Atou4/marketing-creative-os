Start here

Open the vault in Obsidian, or give its folder to your agent. Read context before requesting creative.

  1. Open 00-Home/Quickstart.
  2. Read MASTER-CONTEXT, Brand Voice, Visual Identity, and Claims Whitelist.
  3. Open the relevant project in 13-Projects.
  4. Ask the agent to search the vault and cite the notes it used.
Core loop: search the vault → choose a goal → choose an audience → choose an angle → write a brief → create → review → approve → publish → record what was learned.

For Nursery Pro, begin with Nursery Pro Brand Identity, then read the project brief, content pillars, matrix, and creative direction in 13-Projects/Nursery-Pro.

First instruction to any agent

Work from this vault. Read README.md, AGENTS.md, SKILL.md, 01-Brand-Brain/MASTER-CONTEXT.md, and the relevant project notes before answering. Search the vault first, cite the file paths you used, separate facts from suggestions, and do not invent claims.

If the tool supports wiki commands, use:

/wiki-query @marketing-creative-os What do we know about Nursery Pro's audience, voice, and approved claims?

Otherwise say:

Search this vault for Nursery Pro audience, voice, and approved claims. Cite the source paths. Separate what is known, what is a hypothesis, and what is missing.

Include these four things in a request

Goal

What decision or deliverable is needed?

Audience

Who will read or use it?

Format + constraints

Channel, length, language, deadline, claims, and available assets.

Copy-and-paste prompt library

Query the vault

Search this vault before answering: [topic]. Read MASTER-CONTEXT.md and the most relevant project notes. Return a short answer with cited file paths, then list contradictions, unknowns, and claims that need validation.

Plan a campaign

Use the campaign-strategy skill. Plan a campaign for [product/project] aimed at [audience] with the goal [goal] on [channel]. Read brand context, content pillars, claims whitelist, and recent performance notes first. Return the insight, positioning, angle slate, formats, brief, measurement plan, and open questions. Do not invent proof.

Static social post

Use the social-static skill. Create three post directions for [topic] and [audience]. Follow the brand voice and visual identity. Give the hook, body copy, CTA, visual concept, required asset, and claim check.

Carousel

Use the carousel skill. Turn [source idea] into a [number]-slide carousel for [platform]. Cite the source notes, write one idea per slide, include the caption and CTA, and flag anything needing evidence or design review.

Reel or short

Use the reel skill. Create a [duration]-second concept for [audience] about [topic]. Include the first-second hook, shot list, on-screen text, voiceover, caption, CTA, and safe-to-claim notes.

UGC brief

Use the UGC skill. Draft a creator brief for [product/problem] aimed at [audience]. Include the situation, talking points, allowed proof, do-not-say list, shot prompts, disclosure reminder, and approval checklist. Do not script a fake personal result.

Paid ad

Use the paid-ad skill. Build [number] ad variants for [platform] promoting [offer] to [audience]. Use approved claims only. Include copy, CTA, creative direction, landing-page message match, and experiment variable. Flag validation needs.

Repurpose

Use the repurpose skill. Start from [approved note or asset] and adapt it into [formats/channels]. Preserve the insight and claim boundaries. Show what changes per platform and what stays consistent.

Review creative

Use the creative-review skill. Review [file, copy, or URL] against voice, visual identity, audience, accessibility, platform fit, and claims whitelist. Classify findings as must fix, should fix, or polish. Give a precise correction for every finding.

Review performance

Use the performance-retro skill. Compare [metrics or note] with the campaign brief and previous learning. Separate signal from noise, identify likely causes, recommend the next test, and write the durable lesson for 11-Performance/.

Add research

Ingest this source: [URL/file/text]. Identify whether it is evidence, inspiration, community opinion, or an internal decision. Summarize only what it supports, preserve the link, connect it to relevant notes, and list follow-up questions. Do not overwrite knowledge silently.

Approval and safety rules

Human approval is required before publishing, spending money, changing public claims, or using customer or child-related information.
  • Use evidence from the vault or mark the claim for validation.
  • Never invent testimonials, statistics, certifications, customer numbers, or product capabilities.
  • Confirm imagery, logos, quotes, and music are licensed or approved.
  • Review language, accessibility, and the final creative at actual mobile size.
  • Ask the agent to separate evidence, inspiration, community opinion, and proposal.

After a session

  1. Review the agent’s file changes and remove anything speculative.
  2. Ask for a summary of decisions, open questions, and sources used.
  3. Save durable learning in the correct folder, especially 11-Performance.
  4. Run the vault doctor check if the wiki tool is installed.
  5. Sync only after review.
PYTHONPATH=/Users/macbookpro/Documents/tools/obsidian-wiki \
python3 -m obsidian_wiki.cli doctor \
--vault /Users/macbookpro/Downloads/marketing-creative-os
