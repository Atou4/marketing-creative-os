# Repo Ingest — Simplicio Marketing Engine

Source: https://github.com/wesleysimplicio/simplicio-loop-marketing  
License observed: Apache-2.0

## Useful patterns ingested
- Provider-agnostic routing for LLM, image, video and publishing tools.
- Pipeline: brief → script → creative → caption → compliance → publish → metrics → ads.
- Host-project scanning can draft brand/persona/content-pillar context.
- Compliance and technical QA are gates, not optional polish.
- Analytics feed winner classification and future promotion.
- Creative tooling can route to different providers by task type.

## Adopt
Provider abstraction, Definition of Done gates, technical specs QA, feedback from metrics into future creative.
