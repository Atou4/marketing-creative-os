# Repo Ingest — Marketing Skills

Source: https://github.com/coreyhaines31/marketingskills  
Evidence: public repository

## Useful patterns ingested
- A single product-marketing context document is read by downstream skills.
- Context includes audience, JTBD, pains, competition, differentiation, objections, switching dynamics, customer language, brand voice and proof.
- Social planning uses content pillars, hooks, repurposing, engagement and performance review.
- Ad creative distinguishes generation, performance iteration, grounded batches, and strategic roadmap modes.
- Grounded batch inputs: recent winning ads, customer reviews, comments, brand assets.
- Every concept should trace to real input; comments are useful for objections and unexpected praise.
- Marketing loops define cadence, action condition, self-check, state/idempotency, stop condition, human checkpoint and output.

## Adopt
MASTER-CONTEXT, grounded input corpus, angle-first production, performance loop, stateful recurring workflows.
