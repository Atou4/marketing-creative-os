# Metric Definitions

Define metrics consistently before comparing content.

## Organic examples
- Reach / impressions
- Saves
- Shares
- Comments
- Profile visits
- Link clicks
- Follows attributed
- DMs/leads

## Paid examples
- CTR / outbound CTR
- CPM
- CPC
- CVR
- CPA/CAC
- ROAS/revenue where attribution is reliable
- Hook/hold/watch metrics for video

Document platform-specific definitions because similarly named metrics may not mean the same thing.
