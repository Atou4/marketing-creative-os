# Angle to Format

| Angle need | Good formats |
|---|---|
| Explain a framework | Carousel / LinkedIn document |
| Demonstrate behavior | Reel / screen-record / product demo |
| Human trust | UGC / founder / customer story |
| One sharp claim | Static / quote card / native text |
| Handle objections | FAQ carousel / founder video / comment-response video |
| Compare approaches | Carousel / split-screen / static comparison |
| Timely reaction | Native text / short video / story |

Choose format from the communication job, not from what the image model is best at.
