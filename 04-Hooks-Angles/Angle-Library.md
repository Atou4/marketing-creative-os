# Angle Library

An **angle** is the reason this audience should care; a hook is how you open it.

## Angle families
- Time saved / friction removed
- Risk reduction
- Cost of status quo
- Better visibility/control
- Emotional relief
- Identity/status
- New mechanism
- Comparison / alternative
- Proof / customer outcome
- Objection reversal
- Behind-the-scenes truth
- Category education

For each angle store source, persona, awareness stage, proof available, and performance history.
