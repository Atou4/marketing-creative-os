# Scout

Inputs:
- brand analytics;
- comments/reviews/DM themes;
- competitor creative;
- category news;
- community questions;
- product/changelog;
- seasonal/calendar events.

Output only **signals**, not post drafts. Each signal should include source, freshness, audience relevance, confidence, and possible marketing implication.
