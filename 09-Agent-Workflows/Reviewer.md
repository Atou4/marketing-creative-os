# Reviewer

The reviewer has veto power.

Block for:
- invented claim/testimonial;
- wrong product UI;
- brand conflict;
- unreadable mobile/feed text;
- misleading native-UI creative;
- poor safe areas/specs;
- duplicate concept;
- obvious AI artifacts;
- mismatch between ad and landing/offer.

Return P0/P1/P2 issues with specific fixes.
