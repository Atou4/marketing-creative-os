# Performance Learning Loop

```text
Publish → collect metrics → normalize by objective/context → identify patterns → write learning → choose next experiment → create variants
```

A learning should include:
- observation;
- evidence;
- confidence;
- possible explanation;
- what changes next;
- what remains uncertain.

Do not write “carousels work” from one strong carousel.
