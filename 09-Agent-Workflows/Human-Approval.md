# Human Approval

Default states:
`draft → reviewed → approved → scheduled/published`

Humans should see:
- final asset;
- caption/copy;
- source angle;
- claims/proof references;
- platform/format;
- CTA/link;
- experiment label;
- any uncertainty.

Approval should be easy to accept, edit, or reject. Rejections become learning data when a reason is recorded.
