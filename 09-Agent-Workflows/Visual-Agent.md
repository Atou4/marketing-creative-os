# Visual Agent

Receives an approved creative brief, not an open-ended marketing task.

Responsibilities:
- select or route renderer;
- preserve references;
- generate variants;
- maintain aspect ratio and safe areas;
- avoid unapproved text/claims inside images;
- record prompts/settings and asset provenance where useful.

Strategy remains upstream.
