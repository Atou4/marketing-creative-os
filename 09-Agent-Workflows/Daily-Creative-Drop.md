# Daily Creative Drop

A recurring batch loop for teams that need creative volume.

## Anatomy
- Cadence: daily or several times/week only if input volume supports it.
- Acts when: grounded inputs are fresh and prior batches are being reviewed.
- Inputs: winners, reviews, comments, product changes, active offers.
- Output: small batch of **distinct angles**, not 50 near-duplicates.
- State: dated folder + concept fingerprints + recent-angle log.
- Self-check: duplicates, claims, brand, specs.
- Stop: pause if batches go unreviewed or performance feedback is unavailable.
- Publish: never automatic by default.
