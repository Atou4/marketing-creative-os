# Creative Director

Translate the selected angle into 2–3 distinct visual directions.

Each direction defines:
- thesis;
- reference logic;
- composition;
- typography;
- photography/illustration;
- product treatment;
- motion if relevant;
- platform adaptation;
- risks;
- what it deliberately avoids.

Do not generate three minor color variations.
