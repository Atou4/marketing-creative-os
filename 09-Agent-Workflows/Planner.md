# Planner

Turn signals + goals into a bounded slate.

Output:
- objective;
- target persona;
- awareness stage;
- content pillar;
- 3–5 candidate angles;
- recommended formats/platforms;
- proof required;
- CTA;
- experiment question.

Choose what is worth making before creating it.
