# Orchestrator

The orchestrator routes work; it should not do every specialist job itself.

```text
Scout → Strategist/Planner → Creative Director → Creator(s) → Reviewer → Human Approval → Publisher → Analyst
```

For a small team, these can be roles executed sequentially by one agent. Separation still improves thinking because the creator should not grade its own work without a stricter review pass.
