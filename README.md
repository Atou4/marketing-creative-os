# Marketing Creative OS

An Obsidian-ready marketing and social creative knowledge system for AI agents.

This vault is **not** a giant prompt folder. It separates the durable marketing brain from the tools that render images, videos, captions, or posts.

## Core loop

**sense → choose angle → brief → create → review → approve → publish → measure → learn**

## Design principles

- Strategy and brand context live in Markdown, not inside one vendor.
- Higgsfield, image models, video models, Canva, code templates, and publishing tools are replaceable renderers.
- New creative must be grounded in product truth, customer language, existing winners, or a clearly marked hypothesis.
- AI preflight scores are heuristics, never proof that an ad will win.
- Claims, testimonials, statistics, and endorsements must be traceable.
- Human approval is the default before publishing or spending money.
- Performance data updates the system's memory; old posts alone teach tone, not what is worth repeating.
