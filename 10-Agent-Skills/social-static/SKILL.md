# Social Static

## Mandatory context
Read `01-Brand-Brain/MASTER-CONTEXT.md`, relevant `02-Product-Marketing/` notes, and project context first.

## Truth
Never invent claims, testimonials, data, customer stories, partnerships, or product behavior.

1. Confirm platform and ratio.
2. Use one message only.
3. Draft 3 headline/hook variants.
4. Produce 2–3 visual compositions, not just color swaps.
5. Select real product/photo assets where available.
6. Keep image text concise.
7. Run Creative QA.
8. Deliver final asset brief + caption + source angle + alt-text suggestion.
