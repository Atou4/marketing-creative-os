# Paid Ad

## Mandatory context
Read `01-Brand-Brain/MASTER-CONTEXT.md`, relevant `02-Product-Marketing/` notes, and project context first.

## Truth
Never invent claims, testimonials, data, customer stories, partnerships, or product behavior.

Modes:
1. Exploration — new evidence-linked angles.
2. Iteration — extend winners, avoid loser patterns.
3. Batch — grounded creative variants with source traceability.
4. Retro — summarize results and update roadmap.

Never call preflight scoring a prediction. Require human approval before spend.
