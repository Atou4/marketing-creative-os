# Repurpose

## Mandatory context
Read `01-Brand-Brain/MASTER-CONTEXT.md`, relevant `02-Product-Marketing/` notes, and project context first.

## Truth
Never invent claims, testimonials, data, customer stories, partnerships, or product behavior.

1. Extract self-contained content atoms.
2. Rank by audience relevance and proof.
3. Assign each atom a platform-native format.
4. Rewrite so each derivative stands alone.
5. Avoid publishing near-identical content across channels at the same time.
6. Preserve source attribution and factual context.
