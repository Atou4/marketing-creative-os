# Reel

## Mandatory context
Read `01-Brand-Brain/MASTER-CONTEXT.md`, relevant `02-Product-Marketing/` notes, and project context first.

## Truth
Never invent claims, testimonials, data, customer stories, partnerships, or product behavior.

1. Pick one hook and payoff.
2. Write short script.
3. Convert to shot list with visual continuity notes.
4. Lock characters/products/locations/references before generation.
5. Define captions, safe zones, audio, transitions, and CTA.
6. Generate/film, then edit.
7. Inspect first frame and muted playback.
8. Run truth, brand, pacing, artifact, and platform QA.
