# Performance Retro

## Mandatory context
Read `01-Brand-Brain/MASTER-CONTEXT.md`, relevant `02-Product-Marketing/` notes, and project context first.

## Truth
Never invent claims, testimonials, data, customer stories, partnerships, or product behavior.

1. State objective and metric.
2. Normalize for spend/reach/time when possible.
3. Compare angles, formats, hooks, persona, proof, CTA.
4. Separate observations from explanations.
5. Assign confidence.
6. Update Winners/Losers/Learnings.
7. Propose next experiments that preserve winners while testing a new dimension.
