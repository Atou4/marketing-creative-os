# Creative Review

## Mandatory context
Read `01-Brand-Brain/MASTER-CONTEXT.md`, relevant `02-Product-Marketing/` notes, and project context first.

## Truth
Never invent claims, testimonials, data, customer stories, partnerships, or product behavior.

Do not redesign from scratch. Review the actual rendered asset.

Return P0/P1/P2 issues across truth, audience, angle, hook, brand, hierarchy, format, platform fit, CTA, novelty, accessibility, and technical specs.

Block any invented or unsupported factual claim.
