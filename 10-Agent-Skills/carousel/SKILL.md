# Carousel

## Mandatory context
Read `01-Brand-Brain/MASTER-CONTEXT.md`, relevant `02-Product-Marketing/` notes, and project context first.

## Truth
Never invent claims, testimonials, data, customer stories, partnerships, or product behavior.

1. Choose narrative architecture before writing slides.
2. Define slide 1 hook and final payoff/CTA.
3. Outline middle progression.
4. Keep each slide to one job.
5. Vary composition while preserving the same design system.
6. Check mobile readability and swipe continuity.
7. Run duplication/AI-slop review.
8. Output slide-by-slide copy, visual brief, caption, sources, and QA notes.
