# Swipe File

A swipe file stores **why** a creative is useful, not just screenshots.

For each entry use `Templates/Swipe-File-Entry.md` and capture:
- source/link;
- format/platform;
- observable structure;
- hook/angle;
- composition;
- proof;
- what to borrow;
- what not to copy;
- evidence type.
