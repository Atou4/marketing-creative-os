# Repurposing System

Repurposing is transformation, not copy/paste.

```text
pillar content / demo / customer insight
      ↓
content atoms
      ↓
angle selection
      ↓
platform-native formats
```

Possible transformations:
- Reel → carousel that turns the idea into a saveable framework.
- Webinar → short clips + objection carousel + founder post.
- Product demo → 15s reel + screenshot static + FAQ carousel.
- Customer interview → anonymized insight post + approved testimonial creative.

Each child asset must stand alone without requiring the original context.
