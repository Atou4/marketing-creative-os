# Campaign Architecture

A campaign is a connected set of creative, not unrelated posts sharing a hashtag.

## Campaign stack
1. Audience insight
2. Campaign tension / single-minded proposition
3. 3–5 angle families
4. Hero creative
5. Format adaptations
6. Proof/objection creative
7. Retargeting / product-aware creative if paid
8. Learning plan

Every asset should have a role: introduce, deepen, prove, handle objection, convert, or reactivate.
