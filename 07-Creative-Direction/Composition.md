# Composition

Vary composition while preserving brand recognition.

Possible systems:
- subject-left / type-right;
- full-bleed photo + label;
- product UI as hero;
- editorial crop + annotation;
- split comparison;
- modular grid;
- native-interface mimicry only when truthful and non-deceptive;
- large type-led poster.

Never use decorative complexity as a substitute for a sharp idea.
