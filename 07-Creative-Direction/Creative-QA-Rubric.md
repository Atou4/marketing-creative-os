# Creative QA Rubric

Score 1–5; block if truth/compliance fails.

| Dimension | Question |
|---|---|
| Truth | Are all facts/quotes/visual implications accurate? |
| Audience | Is this clearly for the intended person? |
| Angle | Is there one meaningful reason to care? |
| Hook | Does the opening earn attention without misleading? |
| Brand | Is it recognizable and on-voice? |
| Visual | Is hierarchy obvious at feed size? |
| Format | Does it use the chosen format well? |
| Platform | Does it feel native enough for the platform? |
| CTA | Is the next action appropriate? |
| Novelty | Is it sufficiently distinct from recent output? |
| Accessibility | Is text readable and essential meaning not color-only? |
| Technical | Correct ratio, duration, safe areas, export quality? |

Heuristic score helps triage. Real performance decides winners.
