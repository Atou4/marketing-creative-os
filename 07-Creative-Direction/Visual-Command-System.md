# Visual Command System

Compile visuals from explicit variables rather than vague “make it premium” prompts.

## Command fields
- Objective
- Audience
- Format / ratio
- Visual subject
- Environment
- Composition
- Camera / lens feel
- Lighting
- Palette
- Materials/textures
- Typography role
- Product/brand references
- Motion behavior
- Mood
- Negative constraints
- Text overlay requirements
- Truth/claims constraints

## Example skeleton
```yaml
objective: awareness
format: instagram_static_4x5
audience: nursery_director
subject: educator using phone during classroom routine
composition: editorial asymmetry, UI callout secondary
lighting: warm natural daylight
brand_tokens: warm cream, deep ink, one accent
avoid: cartoons, generic SaaS gradient, fake UI, tiny text
```

This system is inspired by the need to translate “taste” into controllable parameters. Treat any external command catalogue as inspiration, not authority.
